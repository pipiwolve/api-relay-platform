# 需求文档

## 1. 应用概述

### 1.1 应用名称
AI API 中转运营管理平台

### 1.2 应用描述
面向大模型 API 中转分发与运营管理的双端 Web 平台，包含「管理端」与「客户端自助门户」。系统通过统一签发站内 API Key，实现请求鉴权、额度预扣、多渠道智能路由、上游鉴权转换、流式及非流式转发以及基于实际 Token 用量的精准结算记账闭环。同时支持下游接入方自主注册登录、管理个人 API Key、查阅消费明细与接入文档。

## 2. 用户与使用场景

### 2.1 目标用户
- **平台管理员/运营人员**：负责配置上游渠道、管理下游用户及分组、调配模型与倍率、监控全站消费与流水、保障系统安全与健康。
- **客户端接入方/下游用户**：自主接入平台的开发者或企业客户，负责创建管理个人 API Key、查看个人余额与消费流水、查阅调用文档。

### 2.2 核心使用场景
- **客户端自助接入**：开发者注册个人账号，登录自助门户获取并管理个人 API Key，查阅调用代码与错误码说明。
- **个人用量监控**：开发者在门户首页与消费明细页实时监控个人余额、今日及历史 Token 消耗趋势与扣费流水。
- **渠道与模型运营**：管理员接入上游渠道，配置模型映射关系、优先级、权重与健康容灾策略。
- **租户与密钥分配**：管理员维护用户分组、调整计费倍率、为下游用户充值额度，或直接进行全量 Key 的审计与管控。
- **请求中转与计费**：下游客户端使用站内 Key 调用中转接口，系统按分组倍率和模型单价扣费并记录流水。

### 3.2 功能说明

#### 3.2.1 客户端公共与自助门户

##### 3.2.1.1 客户端注册与登录
- **用户注册**：支持下游用户输入用户名、密码完成账号注册，注册成功后自动归入默认用户分组并初始化账户余额。
- **用户登录**：支持下游用户通过用户名与密码登录；未登录状态访问门户受保护路由时自动重定向至登录页。
- **登出操作**：支持用户主动退出当前登录态。

##### 3.2.1.2 门户仪表盘
- **账户核心指标**：展示当前用户可用余额、今日消耗金额、今日 Token 消耗量、近 7 日累计消费金额。
- **权限与费率提示**：展示当前所属用户分组名称、计费倍率以及允许调用的模型白名单提示。
- **用量趋势图表**：以动效折线图展示个人近 7 日每日 Token 消耗量与请求频次趋势。

##### 3.2.1.3 我的 API Key
- **个人 Key 列表**：展示当前用户名下的 API Key 列表，包含 Key 名称、脱敏摘要（前缀/后缀可见，主体隐藏）、所属分组、额度限制、创建时间、最后使用时间、当前状态（启用/禁用）。
- **创建 Key**：用户自主新建 API Key。生成的新 Key 明文仅在弹窗中展示一次，提示用户立即复制保存；关闭弹窗后不再展示明文，系统仅留存不可逆哈希摘要。
- **Key 操作**：支持对本人 Key 进行启用、禁用、轮换（重新生成明文并废弃旧 Key）及删除操作。
- **权限隔离**：用户仅可查看与操作自身名下的 Key，禁止跨用户访问。

##### 3.2.1.4 消费明细
- **个人消费流水列表**：展示请求时间、请求模型、上游渠道、输入 Token、输出 Token、扣费金额、计费币种、状态结果。
- **时间范围切换**：支持快捷切换查看「今日」、「近 7 天」、「近 30 天」流水。
- **筛选与检索**：支持按调用模型、上游渠道、时间区间进行组合筛选，仅展示当前登录用户的个人账单数据。

##### 3.2.1.5 调用文档
- **接口端点展示**：面向接入方展示标准 API 转发接口端点地址。
- **多语言示例**：提供 cURL、Python、Node.js 标准调用代码示例，支持代码高亮与一键复制。
- **错误码参考**：列出常见错误状态码说明（如 401 鉴权失败、402 余额不足、403 模型未授权、429 频率超限、503 上游渠道不可用）。
- **限流与建议**：展示 RPM/TPM 请求频率限制规则及重试与并发调用建议。

##### 3.2.1.6 账户设置
- **个人信息管理**：支持查看并修改个人昵称。
- **安全设置**：支持用户自主修改登录密码。
- **资费详情展示**：只读展示当前账号绑定的分组规则、分组倍率及基础费率说明。

---

#### 3.2.2 管理后台

##### 3.2.2.1 管理员登录页面
- **管理员登录**：独立的管理员认证入口，输入管理员用户名与密码完成身份验证后进入管理后台。

##### 3.2.2.2 运营仪表盘
- **核心指标概览**：展示全站今日总请求量、今日 Token 消耗总量、今日消费金额、请求成功率、当前在线渠道数量。
- **全站趋势图表**：展示近 24 小时或近 7 日的全站请求量与 Token 消耗趋势折线图，支持动效渲染。

##### 3.2.2.3 用户与 API Key 管理
- **用户管理**：
  - 用户列表展示：用户名、所属分组、当前余额、已消耗额度、状态（正常/禁用）、创建时间。
  - 用户创建与编辑：支持新增用户、修改所属分组、调整账户状态。
  - 额度充值：支持管理员手动为指定用户增加或扣减可用额度。
- **全局 API Key 管理**：
  - 列表展示：Key 名称、关联用户、Key 摘要（脱敏）、额度限制、到期时间、状态（启用/禁用）、最后使用时间。
  - Key 签发：管理员为指定用户代签发新 Key，明文仅弹窗展示一次，后端仅存储哈希摘要。
  - Key 操作：支持对全站已有 Key 进行启用、禁用、轮换、删除。

##### 3.2.2.4 上游渠道管理
- **渠道列表**：展示渠道名称、渠道类型、上游接口地址、模型列表、优先级、权重、计费倍率、失败冷却状态、健康状态（正常/不可用）。
- **渠道配置**：
  - 支持新增与编辑渠道（OpenAI、Anthropic、Gemini、DeepSeek、自定义端点）。
  - 基础字段：上游 Base URL、上游 API Key（密文存储）、支持的模型列表。
  - 调度策略：配置优先级（数字越小优先级越高）、权重（同优先级加权分流）、渠道费率倍率。
  - 容灾策略：配置失败重试与触发冷却时限（连续失败自动进入冷却状态）。
- **状态控制**：支持一键启用、停用渠道，支持对渠道执行连通性与健康度测试。

##### 3.2.2.5 模型与分组管理
- **模型清单与映射**：
  - 模型列表：展示标准模型名称、基础单价（输入/输出 Token 费率）。
  - 模型别名映射：配置客户端请求的模型名与上游实际模型名的转换映射关系。
- **分组与倍率**：
  - 分组列表：展示分组名称、分组倍率、开放模型白名单、关联用户数。
  - 分组配置：支持新增与编辑分组，设定分组专属计费倍率乘数，以及该分组允许调用的模型白名单。

##### 3.2.2.6 额度账务与流水
- **额度计费逻辑**：展示预扣款、实际使用结算、调用失败退款的处理状态。
- **全局消费流水日志**：
  - 流水列表展示：请求时间、关联用户、API Key 摘要、请求模型、上游渠道、输入 Token、输出 Token、总扣费金额、请求状态码、耗时。
  - 筛选与搜索：支持按用户、API Key、模型名称、渠道、时间范围、状态码进行多条件组合筛选。
- **价格版本记录**：记录历史模型基础费率与分组倍率的调整日志，供对账追溯。

##### 3.2.2.7 消费统计分析
- **多维度统计图表**：
  - 模型维度统计：各模型的 Token 消耗占比与费用占比（动效柱状图/饼图）。
  - 渠道维度统计：各上游渠道的请求量、成功率与费用分布（动效柱状图/折线图）。
  - 用户维度统计：Top 消耗用户的消费排行榜与趋势图。

##### 3.2.2.8 中转 API 端点说明页
- **系统接入说明**：展示统一调用端点、通用错误码表、鉴权规则及调用限制规范。

##### 3.2.2.9 安全与运维基线页
- **安全检查清单**：管理端与业务端隔离状态核验、API Key 哈希存储检查、日志脱敏（严禁记录 Authorization 头与完整上下文 Prompt/Response）合规项、降级策略说明。
- **运维配置参考**：提供系统对接通用中转转发引擎的环境变量与部署配置参考。

## 4. 业务规则与核心逻辑

### 4.1 身份认证与权限隔离体系
1. **双重身份隔离**：平台严格区分「管理员」与「客户端普通用户」身份体系。管理员仅可访问管理端后台，客户端用户仅可访问客户端门户。
2. **数据访问隔离**：在数据存储与查询层面执行严格的用户所有权隔离。客户端用户仅能查询、修改自身名下的 API Key、消费明细与账户信息，绝不允许跨用户读取或操作。

### 4.2 请求中转与调度流程
1. **认 Key**：客户端携带站内 API Key 请求中转接口，校验 Key 的有效性、状态、过期时间及所属用户与分组。
2. **额度预扣**：检查用户余额，根据请求模型的基础预估值预扣对应额度；若余额不足则中断并返回 HTTP 402。
3. **渠道选择**：
   - 根据用户分组的模型白名单筛选可用渠道。
   - 排除处于失败冷却期的渠道。
   - 优先选择最高优先级渠道；同一优先级下按照权重比例加权轮询。
4. **换 Key 转发**：将请求头中的站内 Key 替换为选定渠道的上游 Key，转换模型别名，转发请求至上游 Base URL。
5. **结算记账**：
   - 请求成功：解析上游返回的用量数据，计算最终消费金额并完成扣费结算。
   - 请求失败：释放预扣额度，记录错误状态，触发渠道失败计数。

### 4.3 计费与倍率计算规则
- **总消费金额** = (输入 Token 数量 × 模型输入单价 + 输出 Token 数量 × 模型输出单价) × 模型倍率 × 分组倍率 × 渠道倍率。
- 所有账务流水计算精度保留至小数点后 6 位。

### 4.4 密钥安全与签发规则
- **不可逆存储**：系统对站内 API Key 仅在首次生成或轮换时向用户展示一次完整明文。
- **哈希持久化**：后端与数据库中严禁保存 Key 明文，仅持久化存储其安全哈希摘要及用于检索的前后缀脱敏信息。

### 4.5 渠道容灾与健康检查规则
- 渠道单次请求发生网络超时或上游返回 5xx 错误时，该渠道失败计数加 1。
- 当失败计数达到阈值时，自动将该渠道置为冷却状态并临时剔除，进入设定的冷却时间倒计时。
- 冷却期结束后自动发起健康检查请求，探测成功后恢复上线。

## 5. 异常与边界情况

| 序号 | 异常场景 | 系统行为与提示 | 适用端 |
| :--- | :--- | :--- | :--- |
| 1 | 客户端用户注册已存在的用户名 | 页面提示「用户名已存在」，阻止提交并保留已输入项 | 客户端 |
| 2 | 未登录状态直接访问客户端门户受保护页面 | 自动重定向至客户端登录页，登录成功后跳转回目标页 | 客户端 |
| 3 | 普通客户端用户尝试访问管理后台页面 | 系统判定权限不足，拦截访问并重定向至客户端门户或提示无权访问 | 客户端/管理端 |
| 4 | 客户端使用已禁用/已删除/过期的 Key 调用中转接口 | 中转接口直接拦截，返回 HTTP 401 Unauthorized 状态及错误说明 | 中转接口 |
| 5 | 用户可用余额不足以支付单次调用预扣款 | 中转接口拦截请求，返回 HTTP 402 Payment Required 状态 | 中转接口 |
| 6 | 请求的模型不在用户所属分组的白名单内 | 中转接口拦截请求，返回 HTTP 403 Forbidden 状态 | 中转接口 |
| 7 | 目标模型的所有上游渠道均不可用或处于冷却期 | 触发 Fail-Closed 降级，返回 HTTP 503 Service Unavailable 状态 | 中转接口 |
| 8 | 上游接口发生非 200 响应或传输中断 | 中转接口回滚预扣金额，不扣除用户额度，记录异常流水日志 | 中转接口 |
| 9 | 管理员为用户充值负数或非数字格式 | 页面提示输入合法有效金额，阻止提交 | 管理端 |

## 6. 验收标准

1. 客户端用户能够完成自助注册与登录，进入客户端门户并查看个人余额、分组信息及近 7 日用量趋势图表。
2. 客户端用户能够在「我的 API Key」页面独立创建、禁用、启用、轮换和删除个人 Key；Key 明文仅在生成/轮换时展示一次，用户无法查看或操作其他用户的任何 Key 数据。
3. 客户端用户能够在「消费明细」页面按今日/7天/30天以及模型、渠道筛选本人的用量与扣费记录。
4. 客户端用户能够在「账户设置」中修改昵称与登录密码，在「调用文档」中查看并复制代码示例与错误码说明。
5. 管理员能够通过独立的管理端入口登录后台，管理端保留仪表盘、用户与全局 Key 管理、上游渠道管理、模型与分组、额度账务、消费统计、端点说明与安全基线的全部功能与数据操作能力。
6. 计费引擎能根据「模型单价 × 模型倍率 × 分组倍率 × 渠道倍率」规则准确结算并生成消费流水，余额不足时正确拦截。
7. 全站 UI 保持深色科技风设计语言统一，登录入场、页面转场、卡片交互及图表渲染具备流畅动效。

## 7. 本期不实现功能

1. 暂不支持在线第三方支付网关直接在线充值（仅支持后台管理员手工充值与额度调整）。
2. 暂不支持短信或邮件形式的余额不足告警推送通知。
3. 暂不支持下游普通用户自主创建子租户与二级分发转售计费功能。
